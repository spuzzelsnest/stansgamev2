# stansgamev2

Game project by spuzzelsnest and Stan. Open the `vault/` folder in Obsidian as a vault (not the repository root: Unity's `Library/` would flood it).

## Notes
- [[Stan Airborne Model]]: the 3D model of Stan, a WW2 Irish soldier in British Airborne kit.
- [[Building the Model]]: how to regenerate the model and renders with Blender.

## Repository layout
| Path | Contents |
|---|---|
| `3d-model/final/` | Current model (`stan_airborne.blend`) and its renders |
| `3d-model/body/` | Body-only model and renders |
| `3d-model/kit/` | Airborne kit model and renders |
| `3d-model/photos/` | Face reference sheet and face landmarks |
| `3d-model/build_stan_airborne.py` | Blender script that builds the model |
| `vault/` | Obsidian notes (this folder) |
